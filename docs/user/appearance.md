# Appearance

Telar has one appearance: its default, changed however you like. Everything is in Settings → Appearance, and every change applies right away. There's no Apply button. **Restore Telar's default** at the bottom puts everything back.

## Colour scheme

Light, Dark, or System (follows macOS). Background edits whichever state the window is showing, so switch to dark to edit dark.

## Background

- **Base**: the app colour. It sets the hue and how colourful the surfaces are, and Telar keeps text readable on top of it.
- **Layers**: linear gradients, radial gradients and images stacked over the base. You can reorder them, fade them, and repeat one across the window.
- **Match the other state**: copies the current state's layers to the other one (light or dark). Each state keeps its own base colour.
- **Adjust colours**: the individual colours, folded away. Use them to override one colour the base got wrong.

## Type and surfaces

- **Accent**: the colour for things you act on, like buttons, links and the caret. There are eight to choose from.
- **Interface font** and **Code font**, each with its own size. Text size runs from 13 to 18 px, and you can step it from the command palette.
- **Depth**: how far cards, the composer and menus lift off the page.

## Window

- **Translucency**: lets the desktop show through the window. The desktop app on macOS only. Turning it on rebuilds the window.
- **Layers through canvas and rail**: how much of the layers (and the desktop, when translucent) shows through.
- **Chat width**: how wide the conversation and the composer can grow.

## Where it's kept

The appearance is stored on the host, the Mac running Telar. The desktop app and every browser connected to it wear the same one, and a change made in any of them reaches the others within a few seconds. Translucency and chat width stay with the window you set them in.

The iPhone app doesn't take on the appearance.
